# Calculadora de Costos - Portal del Viento

Calculadora interactiva para calcular costos de producción de alfajores, trufas, conitos y cubanitos.

## Características

✅ Gestión de ingredientes con costos configurables  
✅ Cálculo automático de costos por producto  
✅ 4 métodos de mano de obra flexible por producto  
✅ Margen de ganancia configurable  
✅ Resumen en tiempo real  

## Métodos de mano de obra soportados

- 💰 Costo TOTAL por lote
- 🔢 Costo por UNIDAD
- ⏱️ Costo HORARIO (tarifa/hora × horas estimadas)
- 👥 Por EMPLEADO (múltiples personas con horas y tarifa individual)

## Instalación local

```bash
npm install
npm start
```

Abre [http://localhost:3000](http://localhost:3000)

## Deploy en Vercel

1. Conecta tu repo GitHub con Vercel
2. Vercel detecta automáticamente que es React
3. Deploy completado en ~2-3 minutos

## Tecnología

- React 18
- Tailwind CSS
- Lucide Icons
